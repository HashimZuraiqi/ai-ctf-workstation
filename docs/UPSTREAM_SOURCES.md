# Upstream Sources

This repo installs or integrates upstream projects; it does not vendor their source code.

- OpenAI Codex: https://github.com/openai/codex
- Google Antigravity CLI: https://github.com/google-antigravity/antigravity-cli
- Claude Code: https://github.com/anthropics/claude-code
- Ghidra: https://github.com/NationalSecurityAgency/ghidra
- Ghidra MCP: https://github.com/bethington/ghidra-mcp
- GDB MCP: https://github.com/signal-slot/mcp-gdb
- Playwright MCP: https://github.com/microsoft/playwright-mcp
- Pwndbg: https://github.com/pwndbg/pwndbg
- uv: https://github.com/astral-sh/uv

Check upstream security advisories and release notes before major competition upgrades. This repository pins only the Ghidra distribution/checksum where reproducibility requires it.

Additional workstation tools installed by category phases include:

- RsaCtfTool: https://github.com/RsaCtfTool/RsaCtfTool
- Miniforge: https://github.com/conda-forge/miniforge
- Volatility 3: https://github.com/volatilityfoundation/volatility3
- Maigret: https://github.com/soxoj/maigret

The custom MCP servers in `mcp_servers/` are team code from this repository; they are not upstream third-party servers.
